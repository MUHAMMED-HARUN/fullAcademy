# خطة تحسين Institute وClass

## ترتيب التنفيذ (Dependency Order)

1. **Institute — اختيار عنوان المعهد:** مستقل عن ربط الصفوف، ويعتمد على خدمات العناوين الموجودة.
2. **InstituteClass — ربط عدة صفوف بمعهد:** يعيد استخدام كيانات Institute وClass وإجراء الربط الحالي؛ لذلك يأتي بعدهما.

## بوابة التنفيذ

بعد مراجعة الخطة، ينفذ في المرحلة التالية **الخدمة رقم 1 فقط**. يتوقف العمل بعدها لمراجعة المستخدم ونجاح `dotnet build` و`ESLint` قبل الانتقال للخدمة رقم 2.

## ملاحظات النطاق

- هذه الملفات تخطيط فقط؛ لا تتضمن تغييرات كود أو قاعدة بيانات.
- إجراء ربط عدة صفوف موجود بالفعل في شاشة Class؛ الخطة تستهدف تطويره لا إنشاء إجراء مكرر.
- يحتفظ فهرس `(InstituteID, ClassID)` الفريد الحالي بوظيفته. أي تغيير لسلوك السجلات المحذوفة soft-delete أو migration يحتاج قراراً مسبقاً.
